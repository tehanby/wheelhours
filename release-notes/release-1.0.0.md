# WheelHours Release Notes - Version 1.0.0

## Overview
WheelHours version 1.0.0 is a significant milestone as it marks the initial release of our project, providing basic time tracking functionality.

## New Features
- Initial implementation of user authentication.
- Basic time tracking features including start/stop timers and viewing timesheets.
- Database setup and migration script for initializing the application.

## Bug Fixes
- Resolved issues with database connection strings not being parsed correctly.
- Fixed a bug where timers were not stopping properly when stopped manually.

## Known Issues
- The system currently does not support multi-user environments. This feature is planned for future releases.
- Custom time tracking categories are limited to predefined categories and cannot be user-defined.
