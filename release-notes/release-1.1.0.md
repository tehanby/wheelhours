# WheelHours Release Notes - Version 1.1.0

## Overview
WheelHours version 1.1.0 introduces several improvements and new features to enhance the user experience.

## New Features
- Implementation of multi-user support, allowing multiple users to track their time simultaneously.
- Ability for users to create and manage custom time tracking categories.

## Bug Fixes
- Fixed an issue where timers would not stop properly when stopped via the API.
- Resolved a bug related to incorrect data types being stored in the database.

## Known Issues
- The system still does not support importing timesheets from external sources.
- There is a potential performance degradation for applications with a large number of users or extensive time tracking history.
