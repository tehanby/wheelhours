# WheelHours

This is a sample project for integrating API endpoints and connecting the front-end with backend API endpoints to fetch and display data.

## Getting Started

1. **Backend Server**:
   - Navigate to `backend` directory.
   - Install dependencies: `npm install`.
   - Start the server: `npm start`.

2. **Frontend Application**:
   - Navigate to `frontend` directory.
   - Install dependencies: `npm install`.
   - Start the application: `npm start`.

## API Endpoints

- `GET /api/data`: Fetches data from the backend.

## Notes

- Ensure that the backend server is running before starting the frontend application.
